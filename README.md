# Wetsly Media — Sitio de Car Detailing

Landing page de conversión para **@wetsly_media**, agencia de marketing para
negocios de car detailing. Presenta la historia del fundador, el *Wetsly Growth
System* de 6 pasos, y un CTA para comentar "PROFESIONAL".

## Estructura

| Archivo | Descripción |
|---|---|
| `index.html` | Marcado de la landing page (una sola página, en secciones) |
| `styles.css` | Estilos y tokens de marca (navy `#0B1A33`, brass `#C4A260`) |
| `script.js` | Año dinámico del footer + animaciones de aparición al hacer scroll |

## Marca

- **Titulares:** Anton (condensada, mayúsculas)
- **Cuerpo:** Poppins
- **Paleta:** navy `#0B1A33` / navy profundo `#071123` / brass `#C4A260` /
  brass claro `#D6B880` / papel `#F0EEE8`

## Ver localmente

Abre `index.html` en el navegador, o sirve la carpeta:

```bash
python3 -m http.server 8000
# luego abre http://localhost:8000
```
